智医保

智医保是一个面向大学生群体的中医健康管理与保险服务平台项目。本仓库主要用于展示项目的前端网站和部分功能原型。项目围绕大学生日常亚健康问题、中医调理需求以及相关保险保障展开，希望通过数字化平台将健康测评、风险识别、保险推荐和中医调理服务结合起来，为大学生提供更加便捷的健康管理体验。

网站目前包含首页、产品与服务、平台流程和团队信息四个主要页面。在功能设计上，实现了基础健康信息填写、中医体质选择、舌象图片上传、健康风险评估、保险方案推荐以及模拟在线投保等交互功能，同时也加入了电子调理凭证和中医香包定制等展示模块。部分功能目前仍处于原型演示阶段，尚未连接真实的医疗、保险和支付系统。

技术实现

网站主要使用 HTML、CSS 和 JavaScript 开发，没有使用额外的前端框架。HTML 用于构建网站页面，CSS 负责页面布局、视觉设计及不同设备的适配，JavaScript 主要用于处理用户交互、健康测评结果计算、保险方案推荐和表单信息同步等功能。

整个项目采用比较简单的静态网站结构，index.html 是网站首页，solution.html 主要展示产品功能，platform.html 用于介绍平台服务流程，team.html 用于展示团队信息。网站的样式和交互逻辑分别保存在 style.css 和 script.js 中。

运行方式

下载项目代码后，直接使用浏览器打开 index.html 即可查看网站，也可以在 VS Code 中通过 Live Server 插件运行。目前项目不需要配置数据库或额外安装依赖。

开发说明

这是我在学习网页开发过程中参与完成的一个项目，也是一次将实际创新创业项目需求转化为网站原型的尝试。在开发过程中，我借助了 Google Gemini 辅助完成部分页面代码编写、样式调整以及 JavaScript 交互功能的实现，并根据项目需求对生成的代码进行了修改和整合。

通过这次实践，我对 HTML、CSS 和 JavaScript 在实际网站中的应用有了更直观的认识，也逐渐熟悉了网页结构设计、前端交互实现以及代码调试的基本过程。

本仓库主要用于项目展示与学习交流，网站中的健康评估结果和保险产品信息仅供原型演示参考，不具备实际医疗诊断或保险承保功能。
